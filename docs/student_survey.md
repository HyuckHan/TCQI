# 컴퓨터학전공 재학생 수요조사 설문지(초안)

## 학생용 안내문

안녕하세요. 본 설문은 컴퓨터학전공의 교육과정과 학생지원 프로그램을 개선하기 위해 학생 여러분의 학습 경험과 의견을 확인하는 조사입니다. 현재의 어려움과 앞으로 필요한 교육·지원을 중심으로 응답해 주시기 바랍니다.

- **대상:** 컴퓨터학전공을 주전공·복수전공·부전공으로 이수 중인 재학생
- **구성:** 객관식 22문항, 마지막 자유의견 1문항
- **예상 소요시간:** 약 10분
- **응답 안내:** 이름과 학번을 묻지 않으며, 결과는 개인을 특정하지 않는 집계 형태로 활용합니다. 참여와 응답은 성적평가에 반영하지 않습니다. 답변하기 부담스러운 문항은 건너뛸 수 있습니다.
- **선택 방법:** 단일선택은 1개, 복수선택은 표시된 최대 개수 이내로 선택해 주세요. 최대 개수를 모두 채울 필요는 없습니다. **[단독선택]** 표시는 다른 보기와 함께 선택하지 말아 주세요.
- **기준 시점:** 향후 교육·지원에 대한 문항은 앞으로 약 1년을 생각하여 답해 주세요. ‘최근 1년’의 경험을 묻는 문항은 입학 후 1년이 지나지 않은 경우 입학 이후를 기준으로 답해 주세요.
- ‘기타’를 선택해도 별도 입력은 필요하지 않습니다. 설명을 덧붙이고 싶다면 마지막 자유의견 문항을 이용해 주세요.

## 1. 문항 구성

교수 수·연령 구성과 학생의 입학성적 구간은 운영 여건을 검토하는 자료로만 사용하고, 학생용 안내문과 보기에는 넣지 않았음. AI 시스템이나 특정 융합 분야에 대한 동의를 먼저 구하지 않고, 일반적인 개선 우선순위를 먼저 물은 뒤 세부 수요를 확인하도록 구성하였음. 이는 명확하고 중립적인 문항, 일반 질문과 세부 질문의 순서, 적절한 비해당 응답을 고려하는 설문 작성 원칙을 참고한 설계임.

## 2. 온라인 설문에 옮길 때의 설정

- **단일선택:** 1, 2, 5, 8, 11, 14, 17, 19, 21번. 선택지 하나만 고르는 형식으로 설정함.
- **최대 2개:** 7, 9, 10, 12, 15, 16, 20번.
- **최대 3개:** 3, 6, 13, 18, 22번.
- **해당하는 것 모두:** 4번.
- **유일한 서술형:** 23번. 나머지 문항의 ‘기타’는 일반 선택지로 만들고, ‘기타 직접 입력’ 기능은 사용하지 않음.
- **배타 응답:** [단독선택] 보기는 다른 보기와 함께 고를 수 없도록 설정함. 플랫폼에서 이를 지원하지 않으면 안내를 강조하고, 분석 시 모순 응답을 별도로 표시함. 이를 자동으로 ‘없음’이나 일반 보기 중 하나로 바꾸지 않음.
- **보기 순서:** 순서가 본질적이지 않은 분야·지원 목록은 가능하면 무작위로 제시하고, ‘기타·없음·판단하기 어려움’은 마지막에 고정함. 학년, 횟수와 일수 등 순서가 있는 보기는 순서를 유지함.[2] 이를 지원하지 않는 도구라면 고정 순서로 시행하되 분석 시 선택지 순서의 영향을 고려함.
- **이름·학번·이메일:** 학생용 안내문과 실제 수집 설정을 일치시킴. 이메일 자동 수집 등은 해제하고, 경품 연락처가 필요한 경우에는 설문 응답과 연결되지 않는 별도 신청으로 운영함. 본 초안에서는 경품이나 연락처 수집을 전제하지 않음.
- **응답 부담:** 현재 경험이 없는 학생도 향후 수요 문항에 응답할 수 있으므로 복잡한 분기를 두지 않음. 답변을 원하지 않는 문항은 건너뛸 수 있도록 하고 자유의견도 선택 응답으로 운영함.

## 3. 결과 집계와 해석

1. **응답 범위와 분모를 함께 제시함.** 조사 기간·대상·배포 경로·전체 응답자 수와 학년별 구성, 각 문항의 유효 응답자 수를 보고함. 응답자 구성과 전체 재학생 구성을 비교하여 특정 학년이나 활동 참여자에 편중되었는지 확인함.
2. **복수응답은 사람을 기준으로 계산함.** 항목별 선택률은 ‘해당 보기를 선택한 사람 수 ÷ 해당 문항의 유효 응답자 수’로 계산하고, 합계가 100%를 넘을 수 있음을 표시함. 최대 2~3개를 고른 결과는 순위 응답이 아니므로 선택된 항목 사이의 1·2·3순위를 추정하지 않음. 선택되지 않은 항목도 곧바로 ‘불필요’로 해석하지 않음.
3. **없음·판단 유보·미경험·미응답을 구분함.** ‘필요 없음’과 ‘판단하기 어려움’을 같은 값으로 처리하지 않으며, 미응답을 0이나 부정 응답으로 대체하지 않음. [단독선택]과 다른 보기가 함께 선택된 문항은 모순 응답으로 표시하고, 사전에 정한 기준에 따라 해당 문항만 집계에서 제외하는 등의 처리방법을 보고함.
4. **학년·경험별 차이를 함께 살핌.** 학년별 교육 수요, 상담 경험별 장벽, 비교과 참여 경험별 희망 활동, 학회 참여 상태별 지원 요구를 우선 교차 확인함. 응답자가 적은 집단은 비율의 순위를 단정하지 않고 인원수를 함께 제시함.
5. **경험과 능력, 관심과 실행 수요를 구분함.** 4번은 자기보고 경험이며 객관적인 수행능력 검사 결과가 아님. 8번은 사용 빈도이며 AI 활용 역량이나 과제의 부정행위를 뜻하지 않음. 10·18번 등의 관심·참여 희망은 실제 수강·등록 인원으로 해석하지 않음. 구체적인 시간표·정원 결정에는 해당 프로그램의 별도 신청 확인이 필요함.
6. **영역별 결과를 합산해 단일 점수로 만들지 않음.** 교과 수요, 진로 관심, 상담 필요와 학회 지원은 서로 다른 판단 대상임. 특히 유사한 선택지가 여러 문항에서 선택되었다고 중복 합산하여 우선순위를 과장하지 않음.
7. **교육과정 결정에는 다른 근거를 함께 사용함.** 6번은 교육 강화 수요, 12번은 진출 분야의 관심으로 구분함. 학생의 선택률만으로 필수 교과를 축소하거나 새 과목을 확정하지 않고, 산업체 조사·교과목 계획서·학문적 기초·교수진과 운영 여건을 종합함.

## 4. 배포 전 확인할 사항

- 저학년과 고학년 학생 몇 명에게 문구와 선택지, 실제 응답 시간을 먼저 확인함. ‘약 10분’은 초안의 예상치이므로 사전 점검 후 수정함. 사전 점검의 필요성은 설문 작성 지침을 참고하였으며, 특정 인원수를 의무 기준으로 정한 것은 아님.[2][3]
- 주전공 학생만 조사할지, 복수·부전공 학생도 포함할지 확정하여 안내문의 대상과 2번 보기를 일치시킴. 초안은 세 집단을 포함하는 안임.
- 학회 참여자에게만 설문을 전달하지 않고, 학년별 공지 등 전체 대상에게 닿는 경로로 안내함. 학생대표·학회 운영진의 의견은 전체 응답과 구분하여 참고할 수 있음.
- 10번의 데이터사이언스·HCI·경영학과는 기존 전공, 전자공학·기계공학·화학공학은 신설·전환 예정 전공이라는 기존 논의를 반영한 것임. 학생용 문항은 분야의 관심을 묻는 형태로 작성하였으며, 공동 교과의 개설 확정이나 현재 운영 실적을 전제하지 않음.
- 질문 본문에 개별 교수의 수·연령, 학생의 입학성적 구간, 선호하는 개편 결론을 추가하지 않음. 성적평가와 분리한다는 안내에 맞추어 응답을 운영함.
